About the Project

CHAOS.exe is an interactive frontend experiment in which a seemingly normal website gradually becomes unpredictable as users interact with it.

Each interaction increases the chaos level and can trigger changes in the interface, colors, messages, and visual effects. The experience encourages users to explore the website and discover how its behavior evolves.

The project combines creative design, frontend development, and interactive storytelling to create an entertaining digital experience.

---

Problem Statement

Many websites follow predictable interaction patterns. CHAOS.exe explores how an interface can become more engaging by responding to user actions with unexpected visual changes and playful interactions.

The objective is to create a browser-based experience that encourages curiosity and experimentation through progressive interface transformations.

---

Our Solution

CHAOS.exe uses HTML, CSS, and JavaScript to create an interface that evolves as users interact with it.

A chaos meter tracks the progression, while JavaScript triggers changes in messages, visual effects, and interface behavior. The experience gradually transforms from an orderly website into a deliberately chaotic environment.

The project runs directly in a web browser and does not require a backend or database.

---

Key Features

- Progressive Chaos Engine: Five stages of increasing chaos.
- Live Chaos Meter: Tracks the chaos level from 0 to 100.
- Interactive Controls: Respond to user clicks with changing messages and behavior.
- Visual Glitch Effects: Introduce unusual visual changes as chaos increases.
- Dynamic Messages: Display playful responses to user interactions.
- Fictional System Terminal: Shows simulated diagnostic messages.
- Particle Effects: Provide animated visual feedback.
- Reality Reset: Allows users to restart the experience.
- Browser-Based Experience: Runs without a backend or database.

Only features implemented in the actual website should be listed here.

Installation and Setup

Prerequisites

- A modern web browser such as Google Chrome.
- Visual Studio Code (optional).

Run Locally

1. Open the GitHub repository.
2. Select Code → Download ZIP.
3. Extract the downloaded ZIP file.
4. Open the project folder.
5. Launch "index.html" in your browser.

Alternatively, clone the repository:

git clone YOUR_REPOSITORY_URL

Replace "YOUR_REPOSITORY_URL" with your actual GitHub repository URL.

No backend, database, or API key is required.

---

How to Use

1. Open "index.html" in your browser.
2. Click the main interaction button to increase the chaos level.
3. Observe the changes in the interface and messages.
4. Experiment with the available interaction buttons.
5. Use the reset control to restart the experience.
